# Urban Escape Racing — 주행 프로토타입

Unity **6000.6.0f1**, PC 키보드용 3인칭 차량 주행 프로젝트. 기본 Built-in 렌더러를 사용하며 외부 에셋은 필요 없습니다.

## 실행

1. Unity Hub에서 Add → Add project from disk로 이 폴더를 등록합니다.
2. Unity 6000.6.0f1로 엽니다.
3. `Assets/Scenes/DrivingTest.unity`를 열고 Play를 누릅니다.
4. Game 뷰를 클릭해 키보드 포커스를 줍니다.

| 키 | 동작 |
|---|---|
| W | 전진 가속. 후진 중이면 먼저 제동 |
| S | 제동. 거의 정지하면 후진으로 전환 |
| A / D | 점진적인 좌우 조향 |
| Space | 뒷바퀴 핸드브레이크, 후륜 구동 차단·전륜 구동 유지 |
| R | 시작점으로 복귀하고 속도·회전 초기화 |

Windows 실행 파일이 필요하면 File → Build Profiles에서 Windows를 선택하고 Build합니다. DrivingTest 씬은 빌드 목록에 등록되어 있습니다. 이번 단계에서는 실행 파일 빌드는 수행하지 않았습니다.

## 구현 범위와 조정

- 600×600m 평지, 20m 격자, 반경 60m 코너링 표식과 경계벽.
- 임시 스포츠 세단: 1,550kg Rigidbody, 네 WheelCollider에 동일 구동 토크, 스프링·댐퍼·낮은 무게중심.
- 기계적 최대 조향각은 32도이며, 일반 주행에서는 앞타이어 이동 방향에 맞춰 유효 조향각을 계산합니다. 초당 85도로 점진 반응하며 (반대키 전환은 초당 190도), 입력을 놓으면 중앙으로 복귀합니다.
- 기본 주행은 후륜 접지력을 높여 안정적으로 구성하고, Space로 시작한 드리프트에 이전의 오버스티어 설정을 적용합니다. 감속하면 필요한 횡력이 줄어 회전 여유가 돌아오는 물리 기반 설정입니다. 과도한 미끄러짐이나 전복까지 자동 복구하지는 않습니다.
- 속도에 따라 거리와 FOV가 변하는 추적 카메라, 속도·조향 표시.
- 추격 AI, 도시, 사운드, 실제 차체 모델은 아직 없습니다.

`SedanController`의 driveTorque, brakeTorque, steeringRate, countersteerRate, countersteerAssist는 Inspector에서 조정할 수 있습니다. 타이어 접지력과 고정 최대 조향각은 같은 스크립트에 있습니다. 포르자 수준의 차량 시뮬레이션이 아니라 초기 주행감 평가용입니다.

## 직접 플레이 확인 순서

1. W로 직진 가속 후 S를 계속 눌러 제동 → 후진 전환 확인.
2. 저속에서 A/D를 짧게 누르고 길게 눌러 점진 반응 확인.
3. 원형 표식을 따라 저속으로 회전한 뒤 빠르게 진입해 Space 없이 기본 접지와 코너링 안정성 확인.
4. W를 놓거나 S로 감속하고, 미끄러지는 반대 방향으로 카운터스티어해 자세를 회복하는지 확인.
5. Space로 후륜 미끄러짐, 해제 후 회복, R로 복귀 확인.

코너 회복감과 카메라의 편안함은 실제 플레이로 추가 튜닝해야 합니다. World 1의 건물에는 레이어 8 기반 카메라 장애물 회피가 적용됩니다.

## 검증

Unity batchmode에서 스크립트 컴파일, 씬 저장 및 Physics.Simulate 검증을 수행했습니다. 상세 결과는 `VALIDATION.md`에 기록했습니다. 키보드 이벤트 전달·그래픽·주관적 주행감은 자동 물리 검사 범위 밖입니다.

Editor 메뉴 `Urban Escape/Create Driving Test Scene`은 씬이 없으면 만들고 물리 검사를 실행합니다. 기존 씬 파일은 덮어쓰지 않습니다. 이 메뉴는 다른 씬을 열 수 있으므로 편집 중인 씬을 먼저 저장하세요. 검사는 저장된 씬을 열어 진행하며 검사 중의 차량 상태는 저장하지 않습니다.

## 파일 보존과 Git

작업 전 폴더에는 `.git`만 있었고 기존 게임 파일은 없었습니다. Git 메타데이터와 원격 설정을 보존했고 커밋·푸시는 수행하지 않았습니다. `Assets`(모든 `.meta` 포함), `Packages`, `ProjectSettings`와 문서는 버전 관리 대상입니다. `.gitignore`는 Library, Temp, Logs, UserSettings, 빌드 출력 및 IDE 생성물을 제외합니다.


## 카운터스티어 조정

드리프트 후륜 접지 강도를 1.12로 설정하고 미끄러진 이후 접지도 높여 급격한 스핀을 완화했습니다. 반대키 조향 전환을 빠르게 했으며, 전진 중 지면에 세 바퀴 이상 닿아 있고 실제 미끄러짐에 대응하는 반대키를 누를 때만 회전 감쇠 보조를 적용합니다. 공중·후진에서는 보조하지 않으며 핸드브레이크 중에는 약한 카운터스티어 보조를 유지합니다. 최대 조향각은 32도이며 일반 주행의 실제 각도는 접지 상황에 맞게 조절하고, 횡속도를 강제로 제거하지 않습니다.


## 핸드브레이크 드리프트

Space는 후륜만 제동하며 W를 함께 누르면 전륜 구동을 유지합니다. 지면에서 전진하며 조향할 때 제한된 회전 보조를 더해 뒤를 흘리면서 방향을 바꿀 수 있게 했습니다. 반대키 보조도 절반 강도로 유지합니다. 후륜 접지 전환은 누를 때 0.12초, 놓을 때 핸드브레이크 접지 감소분을 0.45초에 걸쳐 해제하고 후륜 브레이크는 놓는 즉시 해제합니다. Space를 짧게 누르며 A/D로 진입한 뒤, Space를 놓고 반대키로 자세를 잡아보세요. 길게 누르면 감속합니다. 포르자의 물리를 복제한 것은 아니며 아케이드 드리프트 조작성에 맞춘 초기 설정입니다.


## 현재 주행 설정: 기본 접지 / 드리프트

기본 후륜 접지 강도는 1.48, 전륜은 1.35입니다. 약 29km/h 이상에서 조향하며 Space를 누르면 0.2초에 걸쳐 드리프트 설정(전륜 1.25 / 후륜 1.12)으로 전환됩니다. Space 해제 직후에도 드리프트는 이어지고, 가속하며 실제 차체 미끄러짐이 있는 동안 유지됩니다. S 제동·가속 해제·차체 정렬·저속에서는 약 0.75초에 걸쳐 기본 접지로 돌아옵니다. 핸드브레이크 자체의 후륜 브레이크는 해제 즉시 풀립니다. 기본 주행의 한계 미끄러짐은 가능하지만, Space 없이 드리프트 설정이 자동 활성화되지는 않습니다. 급격한 하중 이동만으로 드리프트 모드에 진입하는 기능은 아직 없습니다.


## World 1 도시 씬

현대 도심 월드는 Assets/Scenes/World01_Metro.unity를 열어 실행합니다. 기존 DrivingTest는 보존했습니다. 도시 구성과 검증 범위는 WORLD01.md를 확인하세요.


## 코너 속도 손실 개선 (현재)

Adaptive Steering을 기본 활성화했습니다. 추가 추진력 없이 전륜 이동 방향에 맞게 조향하여 코너에서 타이어가 과도하게 끌리는 현상을 줄입니다. 변경 전후 측정·CSV·비교 방법은 HANDLING.md에 있습니다. 이전 기록의 고속에서도 항상 32도로 꺾는 동작은 Adaptive Steering OFF에서 비교할 수 있습니다.


## 일반 교통 차량
World01에서 Play하면 최대 40대의 우측통행 차량과 작동 신호등이 생성됩니다. 속도 제한은 60km/h이고 충돌 후 AI 주행을 중단하고 물리 반동으로 밀려나다가 5초 뒤 제거됩니다. 상세 동작과 범위는 TRAFFIC.md에 있습니다.
