# Urban Escape Racing — 주행 프로토타입

Unity **6000.6.0f1**, PC 키보드용 3인칭 차량 주행 프로젝트. 기본 Built-in 렌더러를 사용하며 외부 에셋은 필요 없습니다.

## 실행

1. Unity Hub에서 Add → Add project from disk로 이 폴더를 등록합니다.
2. Unity 6000.6.0f1로 엽니다.
3. `Assets/Scenes/CityOutskirts.unity`를 열고 Play를 누릅니다. 평지 비교에는 `DrivingTest.unity`를 사용합니다.
4. Game 뷰를 클릭해 키보드 포커스를 줍니다.

| 키 | 동작 |
|---|---|
| W | 전진 가속. 후진 중이면 먼저 제동 |
| S | 제동. 거의 정지하면 후진으로 전환 |
| A / D | 점진적인 좌우 조향 |
| Space | 뒷바퀴 핸드브레이크, 후륜 구동 차단·전륜 구동 유지 |
| R | 시작점으로 복귀하고 속도·회전 초기화 |

Windows 실행 파일이 필요하면 File → Build Profiles에서 Windows를 선택하고 Build합니다. DrivingTest 씬은 빌드 목록에 등록되어 있습니다. 이번 단계에서는 실행 파일 빌드는 수행하지 않았습니다.

## 구현 범위와 조정

- 600×600m 평지, 20m 격자, 반경 60m 코너링 표식과 경계벽.
- 임시 스포츠 세단: 1,550kg Rigidbody, 네 WheelCollider에 동일 구동 토크, 스프링·댐퍼·낮은 무게중심.
- 일반 조향 한도는 30km/h 이하 32도에서 140km/h 이상 7도까지 부드럽게 줄어듭니다. 일반 조향 속도도 초당 85도에서 약 30도로 낮아져 고속 급입력이 완만해집니다. 반대키 전환은 기존 초당 190도를 유지합니다.
- 평상시 뒤 타이어 접지를 앞보다 높여 고속 코너에서 앞이 바깥으로 밀리는 언더스티어 성향입니다. Space를 누르면 후륜 접지가 낮아지고 뒷바퀴가 제동되어 뒤를 흘릴 수 있습니다. 속도·차량 방향을 강제로 맞추지 않습니다.
- 속도에 따라 거리와 FOV가 변하는 추적 카메라, 속도·조향 표시.
- 추격 AI, 도시, 사운드, 실제 차체 모델은 아직 없습니다.

`SedanController`의 driveTorque, brakeTorque, steeringRate, countersteerRate, countersteerAssist는 Inspector에서 조정할 수 있습니다. 타이어 접지력과 속도별 조향 한도는 같은 스크립트에 있습니다. 포르자 수준의 차량 시뮬레이션이 아니라 초기 주행감 평가용입니다.

## 직접 플레이 확인 순서

1. W로 직진 가속 후 S를 계속 눌러 제동 → 후진 전환 확인.
2. 저속에서 A/D를 짧게 누르고 길게 눌러 점진 반응 확인.
3. 같은 코너에 저속과 100~140km/h로 진입해, 고속에서 뒤가 갑자기 돌기보다 앞이 바깥으로 밀리는지 비교. W를 놓거나 S로 감속하면 더 작은 반경으로 돌 수 있는지 확인.
4. 70~100km/h에서 A/D로 진입하면서 Space를 약 0.3~0.5초 누르고 놓습니다. 뒤가 흐르면 반대 방향키를 짧게 눌러 회전을 줄이고, 자세가 잡히면 키를 놓거나 코너 방향으로 조향합니다. 반대키를 계속 누르면 반대쪽으로 돌게 됩니다.
5. 고속 A→D / D→A 전환, Space 해제 후 접지 회복, R로 복귀 확인. 코너에 너무 빠르게 들어가면 핸드브레이크만으로 도로 안에 남는 것을 보장하지 않습니다.

코너 회복감과 카메라의 편안함은 실제 플레이로 추가 튜닝해야 합니다. 카메라 장애물 회피는 이번 빈 평지 범위에 포함하지 않았습니다.

## 검증

Unity batchmode에서 스크립트 컴파일, 씬 저장 및 Physics.Simulate 검증을 수행했습니다. 상세 결과는 `VALIDATION.md`에 기록했습니다. 키보드 이벤트 전달·그래픽·주관적 주행감은 자동 물리 검사 범위 밖입니다.

Editor 메뉴 `Urban Escape/Create Driving Test Scene`은 씬이 없으면 만들고 물리 검사를 실행합니다. 기존 씬 파일은 덮어쓰지 않습니다. 이 메뉴는 다른 씬을 열 수 있으므로 편집 중인 씬을 먼저 저장하세요. 검사는 저장된 씬을 열어 진행하며 검사 중의 차량 상태는 저장하지 않습니다.

## 파일 보존과 Git

작업 전 폴더에는 `.git`만 있었고 기존 게임 파일은 없었습니다. Git 메타데이터와 원격 설정을 보존했고 커밋·푸시는 수행하지 않았습니다. `Assets`(모든 `.meta` 포함), `Packages`, `ProjectSettings`와 문서는 버전 관리 대상입니다. `.gitignore`는 Library, Temp, Logs, UserSettings, 빌드 출력 및 IDE 생성물을 제외합니다.


## 카운터스티어 조정

전진 중 지면에 세 바퀴 이상 닿아 있고 실제 미끄러짐에 대응하는 반대키를 누를 때만 회전 감쇠 보조를 적용합니다. 공중·후진에서는 회전 보조를 하지 않으며 핸드브레이크 중에는 약한 보조를 유지합니다. 실제 슬립과 회전에 반대되는 조향일 때는 슬립각 3~18도에 따라 조향 한도를 최대 32도까지 되돌려 고속에서도 자세를 잡을 여유를 줍니다. 단순히 방향키를 바꿨다는 이유만으로 최대 조향을 풀지는 않습니다. 횡속도는 강제로 제거하지 않습니다.


## 핸드브레이크 드리프트

Space는 후륜만 제동하며 W를 함께 누르면 전륜 구동을 유지합니다. 지면에서 전진하며 조향할 때 제한된 회전 보조를 더해 뒤를 흘리면서 방향을 바꿀 수 있게 했습니다. 반대키 보조도 절반 강도로 유지합니다. 후륜 접지 전환은 누를 때 0.12초, 놓을 때 0.45초로 부드럽게 진행하고 후륜 브레이크는 놓는 즉시 해제합니다. Space를 짧게 누르며 A/D로 진입한 뒤, Space를 놓고 반대키로 자세를 잡아보세요. 길게 누르면 감속합니다. 포르자의 물리를 복제한 것은 아니며 아케이드 드리프트 조작성에 맞춘 초기 설정입니다.
